PrésentationOverview

Deux champs de code sont configurables dans Paramètres → Genesys Cloud :Two code fields are configurable in Settings → Genesys Cloud:

  • additionalJS — exécuté quand le client envoie un message et que le conseiller n'est pas en ligne.runs when the client sends a message and the advisor is offline.
  • advisorAdditionalJS — exécuté quand le conseiller répond et que le client n'est pas en ligne.runs when the advisor replies and the client is offline.

Le code s'exécute dans une fonction async : tu peux utiliser await directement. Les erreurs sont capturées et journalisées dans la console — elles n'interrompent jamais l'envoi du message.The code runs inside an async function: you can use await directly. Errors are caught and logged to the console — they never break the message send flow.

ExemplesExamples

1. Créer un Case Salesforce à la réception d'un message client1. Create a Salesforce Case when a client message arrives

SuppliedName contient l'URL directe vers le thread dans la vue conseiller — le conseiller Salesforce peut ouvrir la conversation en un clic. accountId et threadId sont injectés automatiquement dans le contexte.SuppliedName holds the direct URL to the thread in the advisor view — the Salesforce agent can open the conversation in one click. accountId and threadId are automatically injected into the context.

// Create a Case to notify a new message from the customer when the advisor is offline.
// shortenUrl() uses TinyURL (no account). Localhost URLs are returned as-is
// (external shorteners cannot resolve them), so the snippet adapts automatically:
// - Production: short URL (~28 chars) fits in SuppliedName (80-char limit).
// - Local dev: full URL in Description, customer name in SuppliedName.
if (Salesforce) {
  const advisorUrl = `${location.origin}/app/advisor.html?account=${accountId}&thread=${threadId}`;
  const shortUrl = await Salesforce.shortenUrl(advisorUrl);
  const fits = shortUrl.length <= 80;
  await Salesforce.createCase({
    Subject: `Message securise - ${persona.firstName} ${persona.lastName}`,
    Description: fits ? messageText : `${messageText}\n\nLien conseiller: ${advisorUrl}`,
    Origin: "Web",
    Status: "New",
    Priority: "Medium",
    SuppliedName: fits ? shortUrl : `${persona.firstName} ${persona.lastName}`,
    Routed__c: true,
    ...(salesforce.contactId ? { ContactId: salesforce.contactId } : {})
  });
}

3. Notifier le client par SMS via un Workflow Genesys3. Notify the customer by SMS via a Genesys Workflow

Pourquoi un Workflow et pas l'API agentless ? L'endpoint /api/v2/conversations/messages/agentless exige un grant OAuth de type Client Credentials (machine-to-machine). Le grant utilisé ici est Authorization Code + PKCE (contexte client) — Genesys refuse les appels agentless avec ce type de token. La solution est d'exécuter un Workflow Genesys via /api/v2/flows/executions : le Workflow, lui, tourne avec les droits de la plateforme et peut envoyer le SMS sans contrainte de grant.Why a Workflow and not the agentless API? The /api/v2/conversations/messages/agentless endpoint requires a Client Credentials OAuth grant (machine-to-machine). The grant used here is Authorization Code + PKCE (client context) — Genesys rejects agentless calls with this token type. The solution is to execute a Genesys Workflow via /api/v2/flows/executions: the Workflow runs with platform-level permissions and can send the SMS without grant restrictions.

Les variables passées au Workflow doivent être préfixées par Flow. — c'est la convention Architect pour les variables d'entrée d'un Workflow.Variables passed to the Workflow must be prefixed with Flow. — this is the Architect convention for Workflow input variables.

// Execute a Workflow: notify the customer by SMS when the advisor replies
// while the customer is offline. Uses a Workflow instead of the agentless
// API because Authorization Code + PKCE tokens are rejected by agentless.
await fetchGenesysJSON("/api/v2/flows/executions", {
  method: "POST",
  body: {
    flowId: "cef45ea9-5768-441d-a840-595a2d6e3bb4",
    inputData: {
      "Flow.from": "+33644603451",
      "Flow.to": persona.phone,
      "Flow.message": `Bonjour ${persona.firstName}, votre conseiller vous a repondu dans la messagerie securisee.`
    }
  }
});
